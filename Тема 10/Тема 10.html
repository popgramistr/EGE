📝Теория: маска и адрес сети

  • IP-адрес — уникальный 32-битный адрес устройства в сети, записывается как 4 байта через точку (например, 192.168.1.1).
  • Маска сети — двоичное число, в котором сначала (в старших разрядах) стоят единицы, а с некоторого места — нули. Единицы определяют, какая часть адреса относится к номеру сети, нули — к номеру узла в этой сети.
  • Адрес сети (Host) получается применением побитовой конъюнкции (И) к IP-адресу узла и маске: Host = Mask & IP.
  • Широковещательный адрес — адрес, в котором на месте нулей маски стоят единицы. Он и адрес сети не могут быть присвоены обычному устройству.
  • Количество адресов в сети = 2 в степени количества нулевых бит маски (это количество включает адрес сети и широковещательный адрес).
Пример: IP-адрес узла — 231.32.255.131, маска — 255.255.240.0. Тогда адрес сети — 231.32.240.0.

Маска в двух видах записи

Одну и ту же маску можно записать либо количеством единичных бит (CIDR, например /24), либо four-byte-строкой (например 255.255.255.0). Таблица ниже помогает быстро переводить один байт маски между этими видами:

🐍Библиотека ipaddress

Библиотека ipaddress избавляет от ручной побитовой арифметики: она сама переводит адреса в двоичный вид, вычисляет адрес сети и умеет перебирать все адреса сети циклом. Для заданий Темы 10 нужна фактически одна функция:

💡 Импорт: 
from ipaddress import ip_network
Синтаксис: 
ip_network('IP/маска', strict=False)

Маску после / можно указать числом бит (/24) или десятичной строкой (/255.255.255.0) — оба варианта равнозначны.

⚠️ Параметр strict: если в переданном адресе есть «единицы» в части номера узла (т.е. это не «чистый» адрес сети), без strict=False Python выбросит ошибку. Поэтому в задачах Темы 10 strict=False указывается всегда.

1️⃣Тип 1. Подсчёт адресов по битовому условию

Дан IP-адрес узла и маска сети целиком. Нужно посчитать, сколько адресов сети удовлетворяет какому-то условию на биты (количество единиц, соотношение нулей и единиц в байте и т.п.).

Пример

Сеть задана IP-адресом 198.51.100.80 и маской 255.255.255.248. Сколько в этой сети IP-адресов, для которых количество единиц в двоичной записи адреса не кратно 3?

Способ 1. Устное (ручное) решение

Шаг 1. Переводим маску в биты: 248 = 1111 1000 → 5 сетевых бит в последнем байте. Всего сетевых бит: 24 + 5 = 29, значит на узел остаётся 3 бита → в сети 2³ = 8 адресов.

Шаг 2. Считаем количество единиц в неизменной части адреса (первые 3 байта + старшие 5 бит последнего байта):

198 = 1100 0110 (4 единицы), 51 = 0011 0011 (4 единицы), 100 = 0110 0100 (3 единицы), старшие 5 бит байта 80 = 01010 (2 единицы). Итого фиксированных единиц: 4+4+3+2 = 13.

Шаг 3. Перебираем оставшиеся 3 бита узла (000…111) и прибавляем количество единиц в них к 13 — если сумма не кратна 3, адрес подходит:

3 бита узлаАдресЕдиниц в узлеВсего единицПодходит?
000198.51.100.80013✅ да (13 % 3 = 1)
001198.51.100.81114✅ да (14 % 3 = 2)
010198.51.100.82114✅ да
011198.51.100.83215❌ нет (15 % 3 = 0)
100198.51.100.84114✅ да
101198.51.100.85215❌ нет
110198.51.100.86215❌ нет
111198.51.100.87316✅ да (16 % 3 = 1)

Ответ: подходит 5 адресов из 8.

💡 Когда считать вручную: способ 1 удобен, если у сети мало адресов (обычно ≤ 16, маска вида /28 и «длиннее»). Если адресов сотни или тысячи — перебор вручную нереален, нужна программа.

Способ 2. Программное решение

from ipaddress import ip_network

net = ip_network('198.51.100.80/255.255.255.248', False)

count = 0
for ip in net:
    if f'{ip:b}'.count('1') % 3 != 0:
        count += 1
print(count)

Результат: 5 — совпадает с ручным подсчётом.

⚠️ Если сеть большая (маска вида /20 и «короче», тысячи адресов), ручной перебор всех адресов невозможен — метод (шаги 1–2) остаётся тем же для определения количества и структуры бит, но подсчёт по условию делает только программа (способ 2).

2️⃣Тип 2. Два узла в одной сети — находим границы сети

Даны два IP-адреса, про которые известно, что они принадлежат одной сети, но маска не задана явно. Нужно найти наименьшую (самую «строгую») сеть, в которую оба адреса помещаются одновременно, а затем что-то посчитать внутри этой сети.

Пример

Узлы с IP-адресами 133.44.76.210 и 133.44.77.5 принадлежат одной сети. Какое наименьшее количество IP-адресов, в двоичной записи которых ровно 14 единиц, может содержаться в этой сети?

Способ 1. Устное (ручное) решение

Шаг 1. Чтобы сеть была наименьшей (значит содержала меньше «лишних» адресов), нужно взять маску максимально возможной длины — такую, при которой оба адреса всё ещё попадают в одну сеть. Для этого сравниваем адреса побитно и ищем, где они расходятся.

Первые два байта совпадают: 133.44 = 133.44. Третий байт сравниваем в двоичном виде:

76 = 0100 1100
77 = 0100 1101

Байты совпадают в первых 7 битах и расходятся только в последнем (младшем) бите. Значит совпадающих бит всего 16 + 7 = 23.

Шаг 2. Значит наибольшая маска, при которой оба узла в одной сети — /23. Адрес сети получаем, обнулив младший бит третьего байта: третий байт 0100 1100 = 76 (чётное число). Сеть — 133.44.76.0/23.

Шаг 3. У сети /23 остаётся 9 бит на узел → 2⁹ = 512 адресов. Перебрать 512 адресов вручную и посчитать среди них адреса с ровно 14 единицами — нереально быстро, поэтому здесь способ 1 заканчивается на определении границ сети, а подсчёт передаём программе.

Способ 2. Программное решение

Найти максимальную длину маски программно можно, перебирая длину маски от 32 к 1 и проверяя, совпадает ли network_address обоих адресов:

from ipaddress import ip_network

a1, a2 = '133.44.76.210', '133.44.77.5'

for mask in range(32, 0, -1):
    net1 = ip_network(f'{a1}/{mask}', False)
    net2 = ip_network(f'{a2}/{mask}', False)
    if net1.network_address == net2.network_address:
        break

net = ip_network(f'{a1}/{mask}', False)
print('Сеть:', net)

count = sum(1 for ip in net if f'{ip:b}'.count('1') == 14)
print('Ответ:', count)

Результат: сеть 133.44.76.0/23, ответ — 126 адресов.

⚠️ Усложнённые варианты этого типа: вместо второго конкретного адреса может быть дано лишь его свойство (например, «первый байт совпадает с четвёртым, а второй — с третьим») или условие может касаться не отдельного адреса, а соотношения количества единиц в адресе сети и номере узла. Метод решения остаётся тем же (найти максимально длинную маску, при которой условие выполняется), но подходящий адрес или маску в таких случаях приходится дополнительно подбирать перебором внутри программы.

3️⃣Тип 3. Наименьший/наибольший адрес узла в сети

Дан IP-адрес одного из узлов сети и маска. Нужно найти наименьший или наибольший адрес, который можно присвоить обычному устройству (то есть не адрес сети и не широковещательный адрес).

Пример — наименьший адрес

Сеть задана IP-адресом узла 172.20.5.130 и маской 255.255.255.192. Определите наименьший IP-адрес, который может быть присвоен компьютеру.

Способ 1. Устное решение

Шаг 1. Маска 192 = 1100 0000 → 2 сетевых бита в последнем байте. Всего сетевых бит: 24+2=26, на узел остаётся 6 бит.

Шаг 2. Находим адрес сети (Host & Mask): последний байт 130 = 1000 0010, оставляем первые 2 бита, остальные обнуляем → 1000 0000 = 128. Адрес сети: 172.20.5.128.

Шаг 3. Наименьший адрес узла — это адрес сети + 1 (последний бит узла ставим в 1, адрес сети трогать нельзя): 172.20.5.129.

Шаг 4. Сумма октетов: 172+20+5+129 = 326.

Способ 2. Программное решение

from ipaddress import ip_network

net = ip_network('172.20.5.130/255.255.255.192', False)
smallest = list(net.hosts())[0]
print(smallest, sum(map(int, str(smallest).split('.'))))

Результат: 172.20.5.129, сумма октетов — 326.

Пример — наибольший адрес

Сеть задана IP-адресом узла 172.20.5.130 и маской 255.255.255.192. Найдите наибольший IP-адрес, который может быть назначен компьютеру.

Способ 1. Устное решение

Шаг 1–2. Как и выше, адрес сети — 172.20.5.128, на узел отведено 6 бит.

Шаг 3. Наибольший адрес узла получают, поставив все биты узла в единицы, кроме последнего (последний бит = 0, иначе получится широковещательный адрес). Последний байт: сетевые биты 10 + узловые биты всё 1, кроме последнего → 1011 1110 = 190.

Наибольший адрес: 172.20.5.190.

Способ 2. Программное решение

from ipaddress import ip_network

net = ip_network('172.20.5.130/255.255.255.192', False)
largest = list(net.hosts())[-1]
print(largest)

Результат: 172.20.5.190.

4️⃣Тип 4. Подбор значения байта маски

Даны два IP-адреса и информация о том, находятся ли они в одной сети или в разных (при одинаковой маске). Нужно найти минимальное или максимальное возможное значение конкретного байта маски.

Пример — узлы в одной сети, максимальный байт маски

Два узла в одной сети: 10.20.30.40 и 10.20.35.40. Укажите наибольшее возможное значение третьего слева байта маски сети.

Способ 1. Устное решение

Чтобы значение маски (а значит и её байта) было наибольшим, нужна максимально длинная общая часть — сравниваем адреса побитно. Первые два байта совпадают (10.20), сравниваем третий байт:

30 = 0001 1110
35 = 0010 0011

Байты совпадают в первых 2 битах (00) и расходятся на третьем. Значит совпадающих бит всего 16 + 2 = 18.

Максимальная маска — /18. Третий байт маски: первые 2 бита — единицы, остальные — нули → 1100 0000 = 192.

Способ 2. Программное решение

from ipaddress import ip_network

a1, a2 = '10.20.30.40', '10.20.35.40'

for prefix in range(32, 0, -1):
    net1 = ip_network(f'{a1}/{prefix}', False)
    net2 = ip_network(f'{a2}/{prefix}', False)
    if net1.network_address == net2.network_address:
        break

mask = ip_network(f'{a1}/{prefix}', False).netmask
print(str(mask).split('.')[2])

Результат: маска 255.255.192.0, третий байт — 192.

Пример — узлы в разных сетях, минимальный байт маски

Узлы 10.20.30.40 и 10.20.31.40 находятся в разных сетях с одинаковой маской. Укажите наименьшее возможное значение третьего слева байта этой маски.

Способ 1. Устное решение

Чтобы адреса оказались в разных сетях, маска должна включать в сетевую часть хотя бы тот бит, в котором адреса впервые расходятся — а чтобы значение маски (и её байта) было наименьшим, берём минимально достаточную длину маски, то есть ровно до первого различающегося бита. Первые два байта совпадают (10.20), сравниваем третий байт:

30 = 0001 1110
31 = 0001 1111

Байты совпадают в первых 7 битах и расходятся только в последнем. Значит нужно захватить в сетевую часть 16 + 8 = 24 бита.

Минимальная маска — /24. Третий байт маски: все 8 бит — единицы → 255.

Способ 2. Программное решение

from ipaddress import ip_network

a1, a2 = '10.20.30.40', '10.20.31.40'

for prefix in range(1, 33):
    net1 = ip_network(f'{a1}/{prefix}', False)
    net2 = ip_network(f'{a2}/{prefix}', False)
    if net1.network_address != net2.network_address:
        break

mask = ip_network(f'{a1}/{prefix}', False).netmask
print(str(mask).split('.')[2])

Результат: маска 255.255.255.0, третий байт — 255.
