📈Тема 13. Динамическое программирование

Количество программ исполнителя, траектории вычислений

  • 📝 Введение
  • 🔹 Тип 1: Без ограничений
  • 🔹 Тип 2: Траектория содержит число
  • 🔹 Тип 3: Траектория не содержит числа
  • 🔹 Тип 4: Ограниченное число команд
  • 🔹 Тип 5: Ограничения на количество команд

📝Введение

Задания 23 типа ЕГЭ по информатике проверяют умение решать задачи методом динамического программирования. Обычно дается исполнитель с набором команд, преобразующих число (например, +1, *2). Требуется найти количество программ, преобразующих начальное число в конечное.

Основные способы решения:

  • Рекурсия (с кэшированием или без): Простая реализация, но может быть медленной для больших чисел.
  • Динамическое программирование (массив): Заполнение массива значений, где dp[i] — количество путей в число i.
В примерах ниже используется рекурсивный подход, так как он наиболее нагляден для этих задач.

🔹Тип 1: Программа без ограничений

Задача:

Исполнитель Май4 преобразует число, записанное на экране. У исполнителя три команды:
1. Прибавь 1
2. Прибавь 2
3. Прибавь 4
Сколько есть программ, которые число 21 преобразуют в число 30?

Решение:

# I тип: Программа без ограничений
def f(x, y):
    if x == y:
        return 1
    if x > y:
        return 0
    return f(x + 1, y) + f(x + 2, y) + f(x + 4, y)

print(f(21, 30))

🔹Тип 2: Траектория содержит число

Задача:

Исполнитель преобразует число на экране. Команды:
1. Прибавить 1
2. Умножить на 3
3. Прибавить 2
Сколько существует программ, для которых при исходном числе 3 результатом является число 14 и при этом траектория вычислений содержит число 9?

💡 Подсказка: Если траектория должна проходить через число K, задача разбивается на два этапа: путь от Start до K и путь от K до End. Результаты перемножаются.

Решение:

# II тип: Траектория содержит число
def f(x, y):
    if x == y:
        return 1
    if x > y:
        return 0
    return f(x + 1, y) + f(x * 3, y) + f(x + 2, y)

# Путь: 3 -> 9 -> 14
print(f(3, 9) * f(9, 14))

🔹Тип 3: Траектория не содержит числа

Задача:

Исполнитель преобразует число на экране. Команды:
A. Прибавить 1
B. Умножить на 2
C. Возвести в квадрат
Сколько существует программ, которые преобразуют исходное число 3 в число 25 и при этом траектория вычислений не содержит числа 14?

⚠️ Важно: Если попадаем в запрещенное число, возвращаем 0 путей.

Решение:

# III тип: Траектория не содержит числа
def f(x, y):
    if x == y:
        return 1
    # Добавляем проверку на запрещенное число (14)
    if x > y or x == 14:
        return 0
    return f(x + 1, y) + f(x * 2, y) + f(x ** 2, y)

print(f(3, 25))

🔹Тип 4: Ограниченное число команд

Задача:

Исполнитель Троечка преобразует число, записанное на доске. Команды:
1. Вычесть 3
2. Умножить на -3
Сколько различных отрицательных результатов можно получить из исходного числа 333 в ходе исполнения программы, содержащей ровно 13 команд?

Решение:

def f(x, step, numbers):
    if step == 13:
        if x < 0:
            numbers.add(x)
        return
    f(x - 3, step + 1, numbers)
    f(x * -3, step + 1, numbers)

nums = set()
f(333, 0, nums)
print(len(nums))

🔹Тип 5: Ограничения на количество команд

Задача:

Исполнитель преобразует число, записанное на экране. Команды:
1. Умножь на 5
2. Умножь на 3
3. Прибавь 45
Сколько существует различных программ, которые преобразуют исходное число 1 в число 2970, и при этом траектория вычислений:
- не более 4 команд «умножь на 5»
- не менее 2 команд «умножь на 3»
- ровно 5 команд «прибавь 45»?

Решение:

def f(x, y, k1, k2, k3):
    if x > y:
        return 0
    if x == y:
        # Проверяем условия на количество команд в конце пути
        return k1 <= 4 and k2 >= 2 and k3 == 5
    
    # Передаем счетчики команд в рекурсию
    return f(x * 5, y, k1 + 1, k2, k3) + \
           f(x * 3, y, k1, k2 + 1, k3) + \
           f(x + 45, y, k1, k2, k3 + 1)

print(f(1, 2970, 0, 0, 0))
