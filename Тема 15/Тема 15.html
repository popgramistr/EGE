📝Введение

Задания 15 типа ЕГЭ по информатике проверяют знание основ логики и умение работать с логическими выражениями. Главная задача — найти параметры, при которых логическое выражение является тождественно истинным (истинно при любых допустимых значениях переменных).

Основные типы задач:

  • Поразрядные операции: Работа с битовыми операциями (&).
  • Отрезки на прямой: Логические выражения с принадлежностью отрезкам.
  • Многомерные области: Системы неравенств с несколькими переменными.
В решениях используется перебор значений с проверкой всех возможных случаев.

🔹Тип 1: Поразрядная конъюнкция

Задача:

Обозначим через m & n поразрядную конъюнкцию неотрицательных целых чисел m и n.
Например, 14 & 5 = 1110₂ & 0101₂ = 0100₂ = 4.
Для какого наименьшего неотрицательного целого числа А формула:

x&77 ≠ 0 → (x&12 = 0 → x&А ≠ 0)

тождественно истинна?

💡 Подсказка: Импликация A → B ложна только когда A истинно, а B ложно. В остальных случаях она истинна.

Решение:

💡 Способ 1: С использованием break/else
for a in range(128):
    for x in range(128):
        if not((x & 77 != 0) <= ((x & 12 == 0) <= (x & a != 0))):
            break
    else:
        print(a)  # Результат: 65
        break
💡 Способ 2: С флагом
for a in range(128):
    f = True
    for x in range(128):
        if not((x & 77 != 0) <= ((x & 12 == 0) <= (x & a != 0))):
            f = False
            break
    if f:
        print(a)  # Результат: 65
        break
💡 Способ 3: С использованием all()
for a in range(128):
    if all(((x & 77 != 0) <= ((x & 12 == 0) <= (x & a != 0))) for x in range(128)):
        print(a)  # Результат: 65
        break

🔹Тип 2: Отрезки на числовой прямой

Задача:

На числовой прямой даны два отрезка: Р = [12, 62] и Q = [52, 92].
Какова наименьшая возможная длина интервала A, что логическое выражение

¬(¬(х ∈ А) ∧ (х ∈ Р)) ∨ (х ∈ Q)

тождественно истинно?

⚠️ Важно: Необходимо перебрать все возможные интервалы A и найти минимальную длину.

Алгебраическое упрощение:

📚 Пошаговое упрощение выражения:

Исходное выражение:
¬(¬(х ∈ А) ∧ (х ∈ Р)) ∨ (х ∈ Q)

Шаг 1: Применяем закон Де Моргана: ¬(A ∧ B) ≡ ¬A ∨ ¬B
¬¬(х ∈ А) ∨ ¬(х ∈ Р) ∨ (х ∈ Q)

Шаг 2: Закон двойного отрицания: ¬¬A ≡ A
(х ∈ А) ∨ ¬(х ∈ Р) ∨ (х ∈ Q)

Итоговая форма:
х ∈ (А ∪ ¬P ∪ Q)

💡 Логический анализ:
  • Для тождественной истинности: А ∪ P̄ ∪ Q = ℝ (вся числовая прямая)
  • P̄ ∪ Q = (-∞, 12) ∪ (62, +∞) ∪ [52, 92] = (-∞, 12) ∪ [52, +∞)
  • Недостающий участок: [12, 52) - должен быть покрыт множеством A
  • Минимальная длина A = 52 - 12 = 40

Графическое решение:

0
12
52
62
92
P = [12, 62]
Q = [52, 92]
A = [12, 52] (длина = 40)

Визуальный анализ:

  • ■ P = [12, 62] - первый отрезок (синий)
  • ■ Q = [52, 92] - второй отрезок (красный)
  • ■ A = [12, 52] - оптимальное решение минимальной длины (зеленый)

Ключевое наблюдение: Критический участок P \ Q = [12, 52) должен быть покрыт интервалом A, что дает минимальную длину = 40.

Решение:

💡 Способ 1: Использование all() и генератора
p = range(12, 62)
q = range(52, 92)
min_len = 100

for begin in range(100):
    for end in range(100):
        a = range(begin, end)
        if all(not (not(x in a) and (x in p)) or (x in q) for x in range(100)):
            min_len = min(min_len, end - begin)
            
print(min_len)  # Результат: 40
💡 Способ 2: С вложенными циклами и break/else
# Второй способ - с break/else
p = range(12, 62)
q = range(52, 92)
min_len = 100
for begin in range(100):
    for end in range(100):
        a = range(begin, end)
        # Проверяем каждое значение x
        for x in range(100):
            if not(not(not(x in a) and (x in p)) or (x in q)):
                break
        else:
            # Если break не сработал, значит выражение истинно для всех x
            min_len = min(min_len, end - begin)
            
print(min_len)  # Результат: 40

🔹Тип 3: Координатная плоскость

Задача:

Для какого наименьшего целого неотрицательного числа А выражение

(x + 2y < A) ∨ (y > x) ∨ (x > 60)

тождественно истинно при любых целых неотрицательных х и y?

💡 Подсказка: Дизъюнкция (ИЛИ) истинна, если хотя бы один из операндов истинен. Ложна только когда все операнды ложны.

Решение:

💡 Способ 1: С флагом
for a in range(400):
    f = True
    for x in range(400):
        for y in range(400):
            if not ((x + 2 * y < a) or (y > x) or (x > 60)):
                f = False
    if f:
        print(a)  # Результат: 122
        break
💡 Способ 2: С использованием all()
for a in range(400):
    if all((x + 2 * y < a) or (y > x) or (x > 60) for x in range(400) for y in range(400)):
        print(a)  # Результат: 122
        break
