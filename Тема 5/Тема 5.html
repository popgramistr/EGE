🔑Используемые функции

Тема задания опирается на три инструмента Python: срезы, строки и функции перевода между системами счисления.

bin(число)

Переводит число из десятичной системы счисления в двоичную.

Возвращает строку в формате 0bXXXXX, которая является двоичным представлением числа.

Поэтому для использования этой функции в вычислениях необходимо избавляться от первых двух символов при помощи среза: bin(число)[2:]

int(строка, система_счисления)

Переводит число, представленное в виде строки из какой-либо системы счисления, в десятичную.

Максимальная система счисления, которую может обработать функция — 36.

Символы строки должны соответствовать символам данной системы счисления.

💡 Совет: Связка bin(n)[2:] и int(строка, 2) позволяет свободно переключаться между десятичным и двоичным представлением числа.

📋Условие задачи

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится двоичная запись числа N.
  2. Далее эта запись обрабатывается по следующему правилу:
    • а) если сумма цифр в двоичной записи числа чётная, то к этой записи слева дописывается 10, а затем два правых разряда заменяются на 00;
    • б) если сумма цифр в двоичной записи числа нечётная, то к этой записи слева дописывается 11, а затем два правых разряда заменяются на 11.

Полученная таким образом запись является двоичной записью искомого числа R.

❓ Вопрос: Укажите максимальное число R, которое может быть получено при обработке числа N, меньшего 30. В ответе запишите это число в десятичной системе счисления.

💻Программное решение

Так как диапазон значений N мал (N < 30), проще всего решить задачу методом подбора — перебрать все подходящие N и найти максимальное R.

Python решение:

maxr = 0
# Решаем методом подбора
for n in range(4, 29):
    # bin(<число>) - функция, переводящая число в двоичную систему (в виде 0b0100101)
    # [2:] - срез, убирающий ненужные 2 символа в начале строки
    binary = bin(n)[2:]
    if binary.count('1') % 2 == 0:
        binary = "10" + binary[:-2] + "00"
    else:
        binary = "11" + binary[:-2] + "11"
    # int(<строка>, <система ИЗ которой переводим>) - переводит строку из любой системы в десятичную
    R = int(binary, 2)
    maxr = max(maxr, R)
print(maxr)

Объяснение кода:

  • range(4, 29): Перебираем натуральные N, меньшие 30 (нижняя граница взята с запасом, чтобы двоичная запись содержала минимум 2 разряда)
  • bin(n)[2:]: Получаем двоичную запись числа n без префикса 0b
  • binary.count('1') % 2: Считаем сумму цифр по модулю 2, то есть чётность количества единиц
  • binary[:-2]: Срез, отбрасывающий два последних (правых) разряда двоичной записи
  • "10" + ... + "00" / "11" + ... + "11": Дописываем слева два разряда и заменяем два правых разряда согласно условию
  • int(binary, 2): Переводим полученную двоичную строку обратно в десятичное число R
  • maxr = max(maxr, R): Запоминаем максимальное найденное значение R

💡Пояснения результатов

Перебор всех N от 4 до 28 позволяет найти R для каждого N и выбрать максимальное значение. Чем больше единиц в двоичной записи N и чем «удачнее» её чётность, тем больше итоговое R.

Пример работы алгоритма (N = 28) — вариант, дающий максимум:

1. Двоичная запись: 2810 = 111002

2. Сумма цифр = 3 (нечётная) ⟹ дописываем 11 слева, заменяем 2 правых разряда на 11: 1111111 = 11111112

3. Переводим в десятичную: 11111112 = 12710

Перебрав все N от 4 до 28, находим, что максимальное значение R достигается именно при N = 28.
