📝Теория

Задания Темы 8 связаны с подсчётом количества кодов (слов), составленных из ограниченного набора букв, а также с определением слова по его порядковому номеру в отсортированном списке и наоборот.

💡 Библиотека itertools: для программного решения используется функция itertools.product(буквы, repeat=n), которая перебирает все коды длины n, составленные из переданных букв (с повторениями). Полное описание библиотеки — на отдельной странице Библиотека itertools.

1️⃣Пример 1. Подсчёт кодов по условиям на буквы

Задание

Борис составляет 6-буквенные коды из букв Б, О, Р, И, С. Буквы Б и Р нужно обязательно использовать ровно по одному разу, букву С можно использовать один раз или не использовать совсем, буквы О и И можно использовать произвольное количество раз или не использовать совсем. Сколько различных кодов может составить Борис?

Способ 1. Устное (комбинаторное) решение

Шаг 1. Буквы Б и Р встречаются в коде ровно по одному разу каждая — выбираем для них 2 позиции из 6 (с учётом порядка, т.к. Б и Р — разные буквы): 6 · 5 = 30 способов.

Шаг 2. Оставшиеся 4 позиции нужно заполнить буквами С, О, И, при этом буква С встречается не более одного раза. Рассмотрим два случая:

  • С не используется — все 4 оставшиеся позиции заполняются буквами О или И (по 2 варианта на каждую позицию): 2⁴ = 16 способов.
  • С используется 1 раз — выбираем 1 из 4 оставшихся позиций под букву С (4 способа), а остальные 3 позиции заполняются буквами О или И: 4 · 2³ = 32 способа.

Шаг 3. Всего вариантов заполнения оставшихся 4 позиций: 16 + 32 = 48.

Шаг 4. Итоговое количество кодов: 30 · 48 = 1440.

Ответ: 1440.

Способ 2. Программное решение

import itertools

count = 0
for s in itertools.product('БОРИС', repeat=6):
    line = ''.join(s)
    if line.count('Б') == 1 and line.count('Р') == 1 and line.count('С') < 2:
        count += 1
print(count)

Результат: 1440 — совпадает с ручным подсчётом.

⚠️ Заметка: если в задании написано, что каждый символ можно использовать только один раз (без повторений), вместо itertools.product нужно использовать itertools.permutations.

2️⃣Пример 2. Слово по его номеру в списке

Задание

Все 5-буквенные слова, составленные из букв Л, Н, Р, Т, записаны в алфавитном порядке. Вот начало списка:

  1. ЛЛЛЛЛ
  2. ЛЛЛЛН
  3. ЛЛЛЛР
  4. ЛЛЛЛТ
  5. ЛЛЛНЛ

Запишите слово, которое стоит на 150-м месте от начала списка.

💡 Идея: список слов длины 5 из 4 букв устроен точно так же, как позиционная система счисления с основанием 4: буквы в порядке следования из условия — это цифры 0, 1, 2, 3 (Л = 0, Н = 1, Р = 2, Т = 3), а слово — это число, записанное 5 цифрами (с ведущими нулями). Поскольку нумерация слов в списке начинается с 1, а перевод в систему счисления начинается с 0, из номера места сначала нужно вычесть 1.
⚠️ Важно: Если бы нужно было бы найти слово на 1-ом месте, то при переводе 1, мы получили бы 1, т.е. ЛЛЛЛН, а на первом месте стоит слово ЛЛЛЛЛ. Поэтому, из-за того, что нумерация слов начинается с 1, нам необходимо отнять 1 от необходимого номера позиции.

Способ 1. Устное (ручное) решение

Шаг 1. Номер слова в списке — 150, переводим в номер по порядку начиная с 0: 150 − 1 = 149.

Шаг 2. Переводим 149 в четверичную систему счисления (5 разрядов, с ведущими нулями):

Разряд (степень 4)4⁴ = 2564³ = 644² = 164¹ = 44⁰ = 1
Деление149 : 256 = 0, ост. 149149 : 64 = 2, ост. 2121 : 16 = 1, ост. 55 : 4 = 1, ост. 11 : 1 = 1, ост. 0
Цифра02111

Шаг 3. Получили число 149₁₀ = 02111₄. Заменяем цифры буквами (0→Л, 1→Н, 2→Р, 3→Т):

0 → Л, 2 → Р, 1 → Н, 1 → Н, 1 → Н.

Ответ: ЛРННН.

Способ 2. Программное решение

from itertools import product

print(list(product('ЛНРТ', repeat=5))[149])

Результат: ('Л', 'Р', 'Н', 'Н', 'Н') → слово ЛРННН, совпадает с ручным подсчётом.

⚠️ Важно: порядок букв для перевода (какая буква — цифра 0, какая — 1 и т.д.) берётся из примера списка слов в условии, а не из формулировки задания — там буквы могут перечисляться в другом порядке.

3️⃣Пример 3. Номер слова в списке (обратная задача)

Задание

Все 6-буквенные слова, составленные из букв А, О, У, записаны в обратном алфавитном порядке. Вот начало списка:

  1. УУУУУУ
  2. УУУУУО
  3. УУУУУА
  4. УУУУОУ

На каком месте от начала списка находится слово ОУУУОО?

Способ 1. Устное (ручное) решение

Шаг 1. Список отсортирован в обратном алфавитном порядке (У, затем О, затем А), значит буквы — это цифры троичной системы счисления в порядке их следования в списке: У = 0, О = 1, А = 2.

Шаг 2. Заменяем буквы слова ОУУУОО на цифры:

БукваОУУУОО
Цифра (осн. 3)100011

Шаг 3. Получили троичное число 100011₃. Переводим в десятичную систему:

1·3⁵ + 0·3⁴ + 0·3³ + 0·3² + 1·3¹ + 1·3⁰ = 243 + 0 + 0 + 0 + 3 + 1 = 247.

Шаг 4. Это номер слова по порядку начиная с 0, а нумерация мест в списке начинается с 1, поэтому прибавляем 1: 247 + 1 = 248.

Ответ: 248.

Способ 2. Программное решение

from itertools import product

count = 1
for p in product('УОА', repeat=6):
    if ''.join(p) == 'ОУУУОО':
        break
    count += 1
print(count)

Результат: 248 — совпадает с ручным подсчётом.
